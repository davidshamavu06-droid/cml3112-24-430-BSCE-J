# CML3112 Week 2 — Proof of Life

## Programme

Civil Engineering

## Project

This project demonstrates basic Python notebook execution, variable
state, CSV file reading, and reproducible execution using Google Colab.

## Files

- proof_of_life.ipynb — main assignment notebook
- site_inspection_log.csv — supplied four-row inspection dataset
- README.md — project description and run instructions

## How to Run

1. Open `proof_of_life.ipynb` in Google Colab.
2. Upload `site_inspection_log.csv` using the Colab Files sidebar.
3. Enter the correct Student Registration Number in the `STUDENT_ID`
   variable.
4. Run the notebook cells in order using Shift + Enter.
5. Restart and Run All before checking the final results.

## Engineering Problem

One engineering problem that data could help with is monitoring cracks
in concrete structures. Regular measurements of crack width could be
used to identify changes in cracking over time and help engineers
monitor structural condition.

## Data Needed

The data could include crack width measurements, the location of each
crack, the date of measurement, and the structure or member being
inspected, collected at regular inspection intervals.

## What I Fixed

I learned that repeatedly running a cell can change its result because
the notebook kernel keeps the current value of variables. I also used
Restart and Run All to ensure that the notebook worked correctly from a
fresh kernel.
